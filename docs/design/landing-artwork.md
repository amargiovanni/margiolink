# Landing artwork

The landing artwork lives in `web/src/assets/`. All files are served locally.

- `link-sculpture.webp`: original artwork generated with the built-in image generation tool on 2026-09-05. The generated PNG was encoded as WebP with its alpha channel and dimensions preserved.
- `dashboard-overview.webp`: encoded from the project screenshot `docs/screenshots/final-local/overview-desktop-dark.jpg`.
- `links-library.webp`: encoded from `docs/screenshots/links-dark.png`.

The product screenshots show illustrative demo data. The QR illustration is an actual QR code for `https://github.com/amargiovanni/margiolink`, generated with the project's existing QR library.

## Artwork prompt

Use case: stylized-concept. Asset type: original hero artwork for MargioLink, a refined open-source short-link and privacy analytics product. Create a premium studio 3D still life of exactly two large interlocking oblong chain links, diagonally composed bottom-left to top-right. Each link is a thick, softly rounded extruded capsule ring with an open center, physical and sculptural rather than a flat icon. One is polished deep forest green, the other pale sage / celadon matte ceramic. Refined subtle reflections, believable occlusion and tactile material. Warm soft studio light from upper left, gentle shadows within the links. View from a modest elevated three-quarter angle. Square image; links occupy about 80 percent of the frame, whole objects visible with breathing room. Genuinely transparent background and preserve alpha; no floor, no background color, no setting. No typography, no UI, no people, no text, no watermark, no other objects. It should feel like an elegant design-studio product photograph, visually simple, strong silhouette and beautifully crafted geometry.
